# PLAN — Excalidraw Next.js App (cloud-saved drawings)

A self-hosted rebuild of [excalidraw.com](https://excalidraw.com/) built on Next.js 16 + Excalidraw 0.18.0, with user
accounts and server-side file persistence. Open-source alternative to Excalidraw+'s paid cloud features (sign in,
save files, switch between drawings).

---

## 4. Database Schema (Drizzle)

```ts
// src/db/schema.ts  — written for libsql, portable to pg
export const users = sqliteTable('users', {
  id: text('id').primaryKey().$defaultFn(() => crypto.randomUUID()),
  email: text('email').notNull().unique(),
  name: text('name'),
  passwordHash: text('password_hash').notNull(),
  image: text('image'),
  createdAt: integer('created_at', { mode: 'timestamp' }).notNull().$defaultFn(() => new Date()),
  updatedAt: integer('updated_at', { mode: 'timestamp' }).notNull().$defaultFn(() => new Date()),
});

export const files = sqliteTable('files', {
  id: text('id').primaryKey().$defaultFn(() => crypto.randomUUID()),
  userId: text('user_id').notNull().references(() => users.id, { onDelete: 'cascade' }),
  name: text('name').notNull().default('Untitled'),
  createdAt: integer('created_at', { mode: 'timestamp' }).notNull().$defaultFn(() => new Date()),
  updatedAt: integer('updated_at', { mode: 'timestamp' }).notNull().$defaultFn(() => new Date()),
  lastOpenedAt: integer('last_opened_at', { mode: 'timestamp' }),
});
```

> **Drawing content (the big Excalidraw JSON) is NOT stored in the DB.** It goes through the Storage factory
> (local filesystem now → S3 / Vercel Blob later). The DB only keeps lightweight metadata. This keeps the
> schema small, portable, and lets us swap storage backends without a migration.

> When we move to Postgres, only `sqliteTable` → `pgTable` + `integer`→`timestamp` swaps; column names/types stay.

## 5. Storage Factory (★ core requirement)

```ts
// src/lib/storage/types.ts
export interface StorageProvider {
  readonly name: string;
  save(fileId: string, data: string): Promise<void>;
  load(fileId: string): Promise<string | null>;
  delete(fileId: string): Promise<void>;
  exists(fileId: string): Promise<boolean>;
}

// src/lib/storage/index.ts  — factory
let _provider: StorageProvider | null = null;
export function getStorageProvider(): StorageProvider {
  if (_provider) return _provider;
  const driver = process.env.STORAGE_DRIVER ?? 'local';
  switch (driver) {
    case 'local':  _provider = new LocalFilesystemProvider(process.env.STORAGE_LOCAL_DIR ?? './storage/drawings'); break;
    // case 's3':   _provider = new S3Provider(...); break;       // future
    // case 'blob': _provider = new VercelBlobProvider(...); break; // future
    default: throw new Error(`Unknown STORAGE_DRIVER: ${driver}`);
  }
  return _provider;
}
```

`LocalFilesystemProvider` writes `{dir}/{fileId}.excalidraw` (UTF-8 JSON). Adding a new backend = implement the
interface + add a `case` — no changes to API routes or the file service.

## 6. Auth Flow

- `src/lib/auth.ts` exports `authOptions` (NextAuth Credentials provider).
- Credentials provider `authorize()`:
  - looks up user by email in Drizzle,
  - verifies password with `bcryptjs.compare`,
  - returns `{ id, email, name }` or `null`.
- JWT session strategy (default for Credentials).
- Signup: `POST /api/auth/signup` → hash password (bcrypt) → insert user → return.
- Client: `<SessionProvider>` + `useSession()`.
- When unauthenticated → guest mode (localStorage autosave); when authenticated → cloud autosave + file list.

## 7. Editor / Excalidraw Integration

**`excalidraw-wrapper.tsx`** (`"use client"`, dynamically imported with `ssr:false` from `page.tsx`):
```tsx
import { Excalidraw } from "@excalidraw/excalidraw";
import "@excalidraw/excalidraw/index.css";
// ... wires theme, initialData, onChange, excalidrawAPI, MainMenu, Sidebar, renderTopRightUI
```

**Load** — on file select: `GET /api/files/[id]/content` → `initialData = JSON.parse(content)`.
**Save** — debounced `onChange` (1.5s) → `excalidrawAPI.getSceneElements()` + `getAppState()` → `PUT /api/files/[id]/content`.
**Guest** — same `onChange` but writes to `localStorage["excalidraw:guest"]`.

**Custom MainMenu** items: New drawing · Open from device · Save · Save As · My Drawings (toggle sidebar) · Sign in/out · Toggle theme.

**Custom Sidebar** (`name="my-drawings"`): lists `GET /api/files` with open / rename / delete actions; "New drawing" button.

**Top-right UI** (`renderTopRightUI`): theme toggle + user avatar menu (or "Sign in" button).

## 8. Quality Gate (pre-commit, exact order, warnings fail)

`scripts/quality-gate.sh` runs sequentially, `set -e`, stops at first failure:

| Step | Command | Warnings → fail flag |
|------|---------|----------------------|
| 1 | `tsgo --noEmit` | (TS has no warnings concept; type errors only) |
| 2 | `oxlint --deny-warnings .` | `--deny-warnings` |
| 3 | `biome check --error-on-warnings .` | `--error-on-warnings` |
| 4 | `eslint --max-warnings 0 .` | `--max-warnings 0` |
| 5 | `jscpd .` then parse JSON → exit 1 if any duplicate block | parse + manual exit 1 |
| 6 | `knip` | exits non-zero on findings |

`.husky/pre-commit` → `bash scripts/quality-gate.sh`.

**Rules**: no `eslint-disable` / `biome-ignore` / `@ts-ignore` / `oxlint-disable` comments anywhere. Lint configs
only touched where strictly necessary (documented in commit messages).

## 11. Risks & Mitigations

| Risk | Mitigation |
|------|-----------|
| Excalidraw CSS conflicts with Tailwind 4 | scope Excalidraw styles; load CSS only in wrapper |
| knip flags shadcn `ui/*` as unused | `knip.json` ignores `src/components/ui/**` (standard for component libs) |
| jscpd flags duplicate CSS classnames in shadcn | set `min-tokens`/`ignore` on generated `ui/**` |
| libsql native module on sandbox | `@libsql/client` is pure-JS; no native deps |
| Strict gate blocks early commits | run gate locally per-milestone, fix before commit |
| Excalidraw needs `window.EXCALIDRAW_ASSET_PATH` for self-hosted fonts | set via `<Script>` to `location.origin` |
